# 网站 SSL API 迁移

旧 Agent 的 `website_ssl.go` 共 13 条路由，本项目已在 `node/api/ssl.go` 注册相同路径：搜索、列表、创建、申请、DNS 解析、删除、按网站/编号查询、更新、节点推送、JSON/文件上传、下载和主节点导入。

`node/service/ssl.go` 提供证书元数据服务：创建申请配置、按域名查询、PEM X.509 解析、过期检查、更新和删除。证书私钥只保存在服务内部，模型 JSON 序列化明确使用 `json:"-"`，下载接口仅返回证书 PEM。

ACME 申请、DNS 挑战和节点推送属于长耗时任务，当前接口返回 `202 Accepted` 并标记 `queued`；后续接入统一调度器时必须保留任务 ID、审计和失败重试，不得在 HTTP 请求中阻塞等待。
